# 과거 실험 JSON 저장 위치

프로그램이 실행되면 이 폴더 안에 다음과 같이 **실제 측정 기록**이 만들어집니다.

```text
data/history/
  stack_backtracking/
    n_4/
      2026..._<실행고유ID>.json
    n_5/
      2026..._<실행고유ID>.json
```

매번 다른 파일명으로 생성되므로 덮어쓰지 않습니다. `storage/history.py`가 자동으로 저장합니다.

- 모든 실행은 저장하되 **과거 시간 예측에 쓰는 기록**은 정상 완료, 오류 없음, Step-by-Step OFF입니다.
- 현재보다 작은 N에서 같은 알고리즘 ID 및 같은 해답 범위의 기록이 두 종류 이상 있어야 예측합니다.
- 폴더가 비어 있는 것은 정상입니다. 처음 실행하는 프로젝트에 측정 결과를 꾸며서 넣지 않았습니다.
- 다른 PC의 JSON을 복사해 합치면 실행 시간 비교의 신뢰성이 낮아질 수 있습니다.
